From a few details to a finished file

Four fields in, one document out. Every step happens in the same page.

Enter details

Add the document type, parties, terms and effective date. Separate terms with semicolons.

Generate

The request goes to the FastAPI backend, which asks Gemini for a full legal draft.

Review and edit

Read the styled preview, then open the editor to change any clause.

Download

Export a branded PDF, a Word file with a terms table, or plain text.

Made for people who are not lawyers

Professional structure and formatting, without the drafting effort.

Many document types

Employment contracts, NDAs, lease agreements, freelance contracts and offer letters.

Editable preview

Change the wording in place before you export. Your edits carry into every format.

Three export formats

PDF with logo and footer on every page, DOCX in Times New Roman, and clean TXT.

Automatic terms table

Semicolon-separated terms become a table in Word and bullet points in PDF.

Custom branding

Add your own logo, fonts and footer so documents look like they came from your company.

Secure by design

The Gemini API key stays in a server-side .env file and never reaches the browser.

How it is built

A simple pipeline: the browser talks to FastAPI, FastAPI talks to Gemini, and formatters produce the files.

Streamlit UIInputs, preview, editor, downloads
FastAPIPOST /generate with a Pydantic DocumentRequest
Gemini generatorai_core/gemini_generator.py builds the prompt
Gemini 1.5 ProReturns the structured legal text
FormattersTXT, DOCX (python-docx), PDF (fpdf)

Project milestones

Model selection and architecture

Chose gemini-1.5-pro for its long context window and structured output, then defined the frontend, backend and AI core.

Core functionality

Built document generation, the editable preview and the TXT, DOCX and PDF formatters.

API logic

Created main.py and routes.py with a health-check route and the /generate endpoint.

Frontend

Designed the Streamlit interface with logo, input fields, dark preview card and download buttons.

Deployment

Set up the virtual environment, requirements.txt and .env, then tested the backend on port 8000 and the UI on 8501.
